2026 cumulative data-update models

Planned incremental comparisons from the baseline data through 2024

Author

Jim Ianelli

Published

October 14, 2026

This sequence records Jim’s intended incremental data updates for the 2026 EBS pollock assessment. Every model inherits all changes from its predecessor. Model 0 is the baseline with data through 2024; model 0.8 is the end of the proposed updated-data sequence. The model endpoint becomes 2026 at model 0.1 and remains 2026 for all subsequent models. Observation years still differ among data streams.

NotePlan and comparison status

These are planned input changes and intended comparisons. No stock assessment fits were run for this wiki update, and no results or convergence checks for this sequence have been evaluated here. Jim expects little change from replacing fishery weight-at-age in model 0.3; that expectation is untested.

ImportantProvisional BTS split and downstream numbering

Jim corrected himself during dictation around the BTS steps. The split between 0.5 (BTS weight-at-age through 2026) and 0.6 (BTS age compositions, biomass index, and covariance through 2026) remains provisional pending his confirmation. The downstream 0.7 ATS and 0.8 AVO model numbers are therefore also provisional. The table retains this proposed split; it does not resolve the ambiguity.

Cumulative run sequence

Each row describes only the new change relative to its predecessor. All other inputs and model settings carry forward unless an explicit change is recorded.

0 Baseline assessment data. Through 2024. Reference for the cumulative updated-data comparisons.
0.1 Update only the total catch biomass time series; extend the model endpoint to 2026. Total catch biomass through 2026. Compare with 0 to assess the catch update together with the extension of the model to 2026.
0.2 Replace bottom trawl survey (BTS) weight-at-age. BTS weights through 2024. Compare with 0.1 to assess revised survey weights over the historical period.

0.4 Update fishery catch-at-age. Fishery age observations through 2025; no 2026 fishery age observations. Compare with 0.3 to assess the catch-at-age update while the model still ends in 2026.

0.6 — provisional Jointly update BTS age compositions, biomass index, and covariance matrix. All three BTS components through 2026. Compare with 0.5 to assess the combined BTS observation update; this does not isolate the three components individually.
0.7 — provisional number Add acoustic-trawl survey (ATS) data. ATS through 2026; previously the most recent data were from 2024. Compare with 0.6 to assess the ATS update after the preceding changes.
0.8 — provisional number Add acoustic vessels of opportunity (AVO) data. AVO through 2026. Compare with 0.7 to assess the AVO update. This completes the proposed updated-data sequence.

Keep the endpoints distinct

The 2026 model endpoint does not imply that every observation stream reaches 2026. In this sequence, fishery catch-at-age reaches 2025 and fishery weight-at-age is replaced through 2024. No 2026 fishery age observations are added at model 0.4 or in the downstream steps. BTS weights are first replaced through 2024 at 0.2, then provisionally extended through 2026 at 0.5. The BTS age compositions, index, and covariance are provisionally extended together at 0.6.

Compare and retain the evidence

Use adjacent-model comparisons to describe each new update conditional on the earlier changes. Compare each updated model with model 0 to describe the cumulative change. These differences depend on the update order; they do not establish an order-independent contribution for each data stream. Keep the 0.1 endpoint extension visible in comparisons with the baseline, and compare common historical years separately from the new terminal years.

For each run, retain the input filenames and hashes, source delivery and coverage dates, model endpoint, inherited control settings, executable or code revision, and any preliminary-data qualifications. Once fits are available, record convergence diagnostics and compare spawning biomass, recruitment, fishing mortality, fit to observations, and any derived reference points or projections using matched definitions. Follow the annual model checks and projection handoff. Results remain to be evaluated.

Source and open decision

This page records Jim’s cumulative model-update instructions supplied on 14 October 2026. It documents the planned sequence, rather than an inventory of verified model input files or fitted runs. Confirm the 0.5/0.6 BTS split and downstream numbering before finalizing run labels. Scientific inputs and run acceptance remain with the owning assessment project.
